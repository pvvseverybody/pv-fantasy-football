# PV Fantasy Football
Production web shell for PV Fantasy Football 2026.

## Vercel
This repo is intended to be connected to the existing `pv-fantasy-football` Vercel project. Pushing to the production branch triggers deployment.

## Current state
The UI and API route contract are deployable. API routes intentionally fail closed until server-side backend credentials/implementation are connected. No demo player or score data is presented as real.
